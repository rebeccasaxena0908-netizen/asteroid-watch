Asteroid Watch: a data engineering project. NASA APIs → Python ETL → MySQL (XAMPP) → FastAPI JSON API → this dashboard.

Data: NASA NeoWs, cross-checked against the JPL Close-Approach Data API.

Earth texture: NASA Blue Marble: Next Generation (NASA Earth Observatory, public domain).

"Potentially hazardous" is NASA's classification, not a prediction of impact.
